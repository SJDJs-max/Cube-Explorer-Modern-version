# 原图案编辑器迁移

`PatternSearch.pas` 的 297 行核心已迁移到 `include/cube/template_search.hpp` 和 `src/core/template_search.cpp`。0.3 按用户要求移除图案编辑器 GUI，保留核心及既有 MCP 接口兼容。这是完整合法魔方的模板枚举器，与给定角棱约束后枚举转动公式的 `Incomp` / `pattern.cpp` 不同。

## 输入与原代码对应

原版最多五个 3×3 模板，每个格子选六种抽象 Type 之一；它们表达同色/异色关系，不指定实际 U/R/F/D/L/B 颜色。现代接口使用标签 0..5，灰色为 5。整个模板全灰时未使用；混合模板中的灰色仍是第六种相等类，不能当未知贴纸。每个面通过 6×5 布尔矩阵选择可用模板；一个面没有可用模板时结果为零，不能按“没有约束”处理。

| 原实现 | 迁移语义 |
| --- | --- |
| `PatternSearch.pas:56–94` | 每模板四次面内旋转及其镜像，共八个 D4 变体 |
| `106–154`、`189–229` | 已填贴纸的实际颜色与抽象类型必须构成双射；同时保留“相等”和“不同”关系 |
| `158–184` | 按 URF…DRB 放入八个不重复角块与三种朝向；完整角配置检查总扭角 |
| `257–293` | 按 UR…BR 放入十二个不重复棱块与两种朝向；检查总翻棱及角棱置换奇偶 |
| `233–252`、`269` | Continuous 检查公共棱两侧的图案连续性，不是找到一条后是否继续的开关 |
| `42–45` | 完整合法状态加入主窗；Find Generators 再调用普通求解器生成真实公式 |

“连续”的精确定义：对每条棱及其两端相邻角，分别看两个相邻面上“棱贴纸与该角贴纸是否同色”；两侧的布尔关系必须相同。未勾选仍继续枚举，只是不增加这项约束。

## 搜索、验证和范围

枚举保留原角/棱赋值次序，逐步用模板约束剪枝，不通过随机抽样代替完整搜索。每次输出前另用完整面的两两相等关系验证模板匹配，并检查完整 cubie 合法性、54 贴纸编码/解码一致和颜色数量。模板重叠不会重复输出同一个赋值状态。

单面八变体是本功能本身的基础操作。原主窗 `AddCube`（`RubikMain.pas:1310–1315`）还会调用 `FaceletCube.IsIsomorphic`（967–1033）过滤全魔方的 48 种同构，并可加入逆置换等价。本次不移植该全局过滤，所以相互空间同构但状态不同的魔方仍分别输出；也不移植 Symmetry Editor 的对称子群/反对称搜索。

取消、结果上限、节点上限、时间上限和穷尽分别报告。零预算表示不限制该项；预算中止不声称枚举完成。状态结果没有虚构的零步公式。MCP `submit_templates` 返回 `kind="cube_state"`，仅真正生成并验证成功时附 `generator`。详细接口见 `mcp/README.md`。

## 已执行验证

`tests/template_search_tests.cpp` 通过 1,950 项检查，日志为 `logs/template-search-tests.txt`。包含 81 个从合法魔方导出的模板组合及 116 个真正手性类型，实际枚举对标签重命名、旋转和镜像保持一致；灰色语义、面无选择、连续约束、错误角扭/棱翻/奇偶、预算与取消均覆盖。

仅允许纯色面和“一边三格同类、其余六格另一类”时，完整枚举恰有 19 个状态，与独立几何模拟得到的复原态及 18 个单面动作状态集合完全一致。0.2 历史版本的 GUI 曾通过 222 项检查，现已移除该 GUI 及其测试目标。当前统一测试和便携发布包记录以 `CORE-VALIDATION.md` 为准。
