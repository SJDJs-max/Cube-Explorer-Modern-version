# 界面与原版行为对应（0.3.1）

依据只读 `RubikMain.pas/.dfm`、`Incomp.pas/.dfm`、`FaceCube.pas` 及用户指定布局迁移。源码位置见 `ORIGINAL-UI-CONTRACT.md`。本页描述当前实现；历史截图不代表当前界面。交付入口为 `dist/CubeExplorerModern-0.3.1/CubeExplorerModern.exe`。

## 布局、配色与缩放

初始左侧收起，右侧仅保留贴纸编辑器，无图案编辑器及切换页签。经典魔方、画笔色、自动修正保持原版相对位置。下方是选择 / 转动 / 重置三列，再下方为公式输入与应用。底部进度条移除，颜色选择位于“选项 → 自定义选中颜色”。转动网格保持：

```
R U F
L D B
r u f
l d b
M E S
x y z
```

重置共九个按钮，空白 / 复原 / 随机各配角、棱按钮。方法选择标题使用较大粗体，与说明区分。方法一展开共同结果列表；方法二打开独立公式弹窗，只有“将解添加到主窗口”才复制结果并展开左侧。结果行保留缩略图、求解 / 生成方向、公式、名称、最优与运行图标。100% 比例下行高基准为 140，缩略图为 168×122；“求解 / 生成”与“名称”标签在同一列，名称标签紧邻输入框。长公式换行时行高随内容增加。

英文字体 Calibri，中文微软雅黑（Microsoft YaHei）。默认姿态为白顶、绿前、红右；URFDLB 对应白、红、绿、黄、橙、蓝，精确 RGB 依次为 `(255,255,255)`、`(238,0,0)`、`(0,216,0)`、`(254,254,0)`、`(255,161,0)`、`(0,0,242)`。这是显示配色，不重排实际贴纸或改写公式。Qt 颜色对话框的 RGB、HSV、取色及标准按钮汉化，保留真实编辑功能。

右上角太阳 / 月亮与选项中的夜晚模式同步。主窗口默认收起 510×730、展开 1120×730；首次展开结果区时按当前屏幕可用区域居中，空间不足时限制窗口尺寸。去掉编辑器底部的额外伸展占位，公式输入后不再留下大块空白。内容按 75%–200% 的共同逻辑比例缩放，Qt 独立处理屏幕 DPI；本文尺寸均为 Qt 逻辑像素。主题不改变求解状态，偏好保存于 `data/preferences.ini`。

经典展开与 2D 布局保持原有结构。3D 按指定参考项目的 TwistyPlayer 使用经度 30°、纬度 35°、20° 视场角的透视相机，含 26 个等尺寸块体、真实倒角、贴纸和柔和明暗；相机无滚转，六面共用一个投影。左键拖动和滚轮只改变观察视角，不改变状态、贴纸编号或算法步数。具体几何及验证见 `CUBE-CANVAS.md`。

程序沿用原 `rubik.ico`，同时嵌入 Windows EXE 图标资源与 Qt 应用资源，用于文件和窗口图标。`assets/rubik.ico` 与只读原件的 SHA-256 均为 `A33D00C855510B89C708F0F0D17B7FE136547AB41D77BD9A5F2CD007AACC8249`，未重绘或改写原图标。

原 `FaceCube.pas` 纹理映射：Shift 为黑底、目标色交叉斜线；Ctrl 为黑底、U色单向斜线。普通贴纸保持纯色。两种纹理对应真实不同约束，不只是绘画装饰。

## 原操作保留

- 中心左键取色，非中心左键染色；Shift 忽略朝向，Ctrl 仅朝向，同时按下时 Shift 优先。
- 非中心右键或中键只清空一个贴纸；中心右键在方向模式下打开方向编辑。
- 自动修正默认开启，左键执行原局部检查，右键清空不触发。关闭时允许暂态不合法状态，转动仍按真实贴纸置换执行。
- 求解 / 生成总会执行提交检查。若输入被修正，则展示结果并暂停这次提交，用户检查后再次点击。
- 转动按钮左键正转、右键按下显示撇号并在松开时逆转；Ctrl / Shift 不改变转角。
- 空白 / 复原的角、棱子按钮保留另一类；随机角、棱会复原另一类，沿用原版差别。
- 中心方向约束关闭后保留原方向，关闭期间的真实转动继续更新，再启用时恢复。

## 公式窗口

初始空闲、按钮“开始搜索”。窗口默认 550×670，以 610×740 为布局缩放参考，支持最小化、最大化和关闭；采用非模态独立窗口，不设置“始终置顶”。文本区在上，允许动作和类别开关在左下，开始 / 清空 / 添加在右下。外层 URFDLB 默认全选；宽转、中层、整体旋转各项初始未选，开启类别不会自动全选，后续切换保留用户选择。参数位于折叠的搜索设置。

默认最大步数不限（核心 -1），时间、节点、结果上限均为 0（不限）。最大步数 0 仍只检查零步。一般枚举按步数递增直到用户停止；初始已目标、只有免费转体等可证明有限情况可正常穷尽。

中文输出按原 `Lines.Add` 方式追加：“计算开始…”、“正在搜索深度 N”、“计算停止。”。相同步数公式集中输出，格式为 `(nf)`，只有核心证明最短时显示 `(nf*)`。不重写历史、不显示旋转统计、不删除或追加 U、不从文字反推计步。当前加速结构为现代部分投影数据库，不能冒称原完整八角数据库。

停止请求后显示“停止中…”，线程真正退出才恢复开始。预算中止不当作穷尽。运行中可以添加全部缓冲结果，重复点击再次复制；清空只在停止后可用。关闭先取消并等待线程退出。核心流式模式不再重复保存全部结果，跨线程投递具有可取消背压，避免队列无限增长。

## 菜单与文件

原 DFM 无独立可编辑地址栏或顶部工具栏；保留文件名标题及文件(F)、编辑(Y)、运行(Z)、选项(O)、帮助(H)访问键。

| 功能 | 实际行为 |
|---|---|
| 加载 / 保存 | CEX 保留部分约束、原始动作、计步、终态；加载先完整验证再替换或追加。旧 TXT 使用原生成方向，支持原 48 贴纸和旧记法 |
| HTML / 打印 | 输出真实图和公式；打印设置可选打印机和属性；打印全部 / 所选使用实际 Qt 打印链 |
| 编辑 / 排序 | Ctrl、Shift、Ctrl+Shift 多选；真实删除，按名称、步数或原角棱 ID 排序 |
| 随机 / WCA | 随机默认 10、上限 100000；原 WCA 入口切标准配色，生成五个合法状态的真实生成式，目标 21 步 |
| 搜索 / 自动运行 | 真实任务、门槛和线程数设置；停止请求传给工作线程 |
| 二阶段设置 | 真实 UD / RL / FB 三轴搜索，默认关闭；总预算共享，结果映射到原朝向；同进程剪枝表复用 |
| 最优 | 调用精确搜索，证明后才显示星号，复选框本身不构成证明 |
| 统计 | 按算法步数显示二阶段、已证最优和公式结果分布，不解析显示文本，不统计旋转 |
| 帮助 / MCP | 打开实际离线帮助 / 配置文件；MCP 文件打开失败明确提示 |
| 右键 | 逆置换、与编辑器相乘 / 与逆相乘作用于真实状态；复制、传入、删除和回放可用 |

Delete 删除所选，Escape 取消加载，Enter 应用公式，Alt+X 退出。Ctrl+F 沿用把最后一条可用求解式写入 `data/ctrlFsave.txt` 的行为。

普通 Solver / Generator 可以切方向；模 U 公式不能用显示层简单取逆替代生成目标。旧 TXT 不足以保存部分约束，拒绝有损导出且不截断原文件。HTML 用静态图替代过时 Java Applet。

## 验证与范围

Qt 专项测试和 `--smoke-test` 覆盖真实编辑、动作、颜色对话框、主题、缩放、中心方向、统计、普通 / 最优 / 公式搜索、文件往返、取消和五打乱菜单；截图来自运行程序。最终统一与便携 EXE 证据见 `CORE-VALIDATION.md`。

相机和高深对称界面按要求排除；旧 HTTP、普通 slice-mode、专用大中心表未启用，不用空菜单代替功能。模板核心及已有 MCP 接口保留兼容，图案编辑器 GUI 已移除。常规二阶段仍精确复原，不采用公式模式的模 U 规则。
