开始使用

解压后双击 CubeExplorerModern.exe 即可运行。请保留整个程序文件夹；内置 Qt 运行库与剪枝数据，无需安装 Delphi、Python 或 Qt，所有求解与验证均在本机离线完成。

初次打开时左侧结果区自动收起，右侧显示现代化的原式贴纸编辑器：顶部可一键切换经典 / 2D / 3D视图与中英双语 / 白天夜晚模式；魔方下方提供 ZBLS、OLL、F2L、OLLCP/COLL 一键标记以及 Cross 快速求解（支持 Cross / XCross / XXCross / XXXCross）；下方控制区依次为“选择”、“转动”、“重置”与“输入公式（含逆公式应用）”。

  1. 点击任意中心贴纸取色，再用左键 / Shift / Ctrl / 右键编辑其他贴纸；或在“输入公式”框输入转动序列，按 Enter（或在任意焦点下按 Ctrl+Enter）直接应用。
  2. 点击“求解当前情况”或“生成当前情况”。完整普通三阶弹出方式选择框；含未知块、忽略朝向、仅朝向或中心方向约束时自动进入方式二（公式窗口）。
  3. 方法一 · 常规求解：在左侧结果列表新增条目并运行二阶段求解；每条结果可另行勾选“最优”执行多线程精确最优搜索。
  4. 方法二 · 公式求解：弹出独立公式窗口，支持外层 / 宽转 / 中层 / 整体转体、逐动作禁用、模 U 与原生 MCC 手感排序；点击“将解添加到主窗口”可把结果加入左侧列表。
方式适用任务目标与计步
方法一 · 常规求解完整普通三阶，快速寻解或精确最优求解18 种外层动作，精确复原，半转计一步（HTM）
方法二 · 公式求解完整或不完整图案（F2L / OLL / ZBLS / Cross 等）默认模 U；外层、宽转、中层各计一步，整体转体不计步并单独限制次数

视图同步、双语与日夜模式

可通过编辑器左上角切换条、菜单“选项 → 魔方显示”或快捷键（默认 F2）在经典展开、2D 展开与3D 魔方之间切换。左侧结果列表中的魔方缩略图会自动跟随主视角同步切换（经典、2D、3D 均完整支持），且导出 HTML 时也会保留当前视角。

在 3D 视图中，不带修饰键的左键拖动可自由旋转观察角度，滚轮缩放，单击仍可直接染色或取色；拖动或重置主界面 3D 视角时，左侧结果列表中的所有 3D 缩略图也会实时跟随同步旋转，且不会改变魔方状态或增加动作。

点击菜单栏右上角的中文 / EN按钮或月亮 / 太阳按钮可即时切换语言与日夜主题；打开帮助（F1）会自动打开对应语言的离线帮助文档。配色、视角、主题、AutoFix、性能模式与自定义快捷键保存在程序目录的 data/preferences.ini。

默认白顶、绿前、红右（U 白 / R 红 / F 绿 / D 黄 / L 橙 / B 蓝）。如需修改某面颜色，先点击该面中心取色，再选择“选项 → 自定义选中颜色…”。

增强公式解析

公式输入框支持标准空格写法，同时也支持无空格连续写法与常见手写习惯：

写法示例等价标准动作说明
RUR'U'R U R' U'无空格连续识别，同样适用于 rUR'U'r'FRF'、M2UM2U2
R'2 / r'2 / Rw'2R2 / r2 / r2自动兼容撇号在前的半转写法与 R2'
Rw / RW / rr宽转（外层 + 相邻中层），单步计费
M E S / x y z中层 / 整体转体中层方向跟随 L、D、F；转体方向跟随 R、U、F

公式中的小写字母（如 r）表示宽转；“编辑 → 输入贴纸状态”中的 54 字符贴纸串里的小写字母表示忽略朝向。

结果列表、多选与多线程最优搜索

左侧每条结果包含同步视角的魔方缩略图、Solver / Generator 方向切换按钮、公式（公式结果附带 [MCC x.x] 评分）、图案名称、最优复选框与运行/停止按钮。支持单击单选、Ctrl 多选、Shift 连续选择；右键缩略图可复制、传送到编辑器、逐步回放、逆置换、相乘或删除。

勾选“最优”并点击运行箭头，将使用多线程三轴 IDA* 精确最优求解器（含惰性 8 角精确剪枝表与前后向择优）。只有引擎严格证明不存在更短公式时，步数后才显示 *。

公式求解、精细禁用与 MCC 手感排序

公式窗口面向竞速玩家做了深度增强：

  • 模 U（Modulo U）：默认开启，求解到达复原或其逻辑 U / U' / U2 等价态即止，不输出末尾 U；必需的首步 U 保留为真实动作并以 [U] 括起显示，不改变真实计步。
  • 逐动作精细禁用：左键勾选/取消字母开关；右键任意动作复选框可弹出菜单单独禁用 90°、180° 或 -90°，也可点击“精细动作…”打开 54 动作矩阵。禁用 F2 等半转时，引擎会自动杜绝 F F、F' F' 以及 F B F 等同层合成绕过。
  • 转体与高级设置：勾选“允许整体旋转”时可设置最大转体次数；展开“搜索设置”可调整转角、步数范围、数量/时间/节点预算、模 U、剪枝强度与免费转体商压缩。
  • 原生 MCC 手感排序：内置 Trangium MCC（Move Count Coefficient）C++20 原生引擎，支持按搜索顺序 / 步数 → MCC / MCC → 步数实时排序，点击“MCC 设置…”可调整全部 10 项手感参数及“去起手 U（忽略 pre-AUF）”。

性能模式与系统保护

程序在“选项 → 性能模式”中提供三档并发策略，避免多线程求解拖卡系统：

  • 静音 / 省电（约 50% 核心）：低风扇噪音，适合笔记本后台运行。
  • 均衡（默认，留核防卡顿）：自动预留 1–2 个逻辑核心并降低后台求解线程优先级，兼顾速度与系统流畅度。
  • 全速（满核并发）：占满全部 CPU 核心，适合极限冲刺最优解或大深度公式枚举。

同时，模式数据库缓存会根据当前机器物理内存自动设定安全上限，防止内存暴涨。每条输出公式都会经过独立的 54 贴纸几何模拟器逐条回放验证。

AI / MCP 批量调用

mcp/CubeExplorerMcp.exe 是本地 stdio MCP 服务，通过常驻 CubeExplorerEngine.exe 调用本机 C++ 求解核心，无需外部 API Key。根目录的 mcp-config.json 已预填路径，支持 get_capabilities、validate_cube、apply_moves、submit_solve、validate_templates、submit_templates、get_job、get_results、cancel_job。详细协议见 MCP 接口说明。
