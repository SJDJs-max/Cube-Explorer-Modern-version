Getting Started

Extract the portable package and launch CubeExplorerModern.exe. Keep the entire folder intact — Qt libraries and pruning data are bundled, so no external Python, Delphi, or Qt installation is required. All solving and verification run 100% locally offline.

On launch, the left results pane starts collapsed so the sticker editor remains focused. At the top you can toggle Classic / 2D Net / 3D Cube views, English / Chinese UI, and Light / Dark Mode. Directly below the cube are one-click speedcubing presets (ZBLS, OLL, F2L, OLLCP/COLL) and the Cross Solver (Cross / XCross / XXCross / XXXCross), followed by Solve, Moves, Reset, and Formula Input controls.

  1. Click any center sticker to pick a brush color, then paint stickers with Left / Shift / Ctrl / Right clicks — or enter a formula and press Enter (or Ctrl+Enter from anywhere in the window) to apply it directly.
  2. Click Solve Cube or Generate Cube. Complete ordinary cubes prompt for Mode 1 vs Mode 2; partial patterns, orientation markers, or center constraints open Mode 2 (Formula Window) directly.
  3. Mode 1 · Ordinary Solver: Adds a row in the left list and runs Kociemba's Two-Phase solver. Check Opt on any row to run the multi-threaded exact optimal solver.
  4. Mode 2 · Formula Solver: Opens an independent window supporting outer, wide, slice, and rotation moves, per-move power bans, Modulo-U goals, and native MCC fingertrick sorting. Click Add Solutions to Main Window to save results into the left pane.

Synchronized Views, Language & Themes

Switch between Classic, 2D Net, and 3D Cube using the top-left pill switcher, Options → Cube View, or the shortcut (default F2). Result thumbnails in the left pane automatically follow the active view mode (Classic, 2D, and 3D), and HTML exports capture the active view as well.

In 3D view, drag with the left mouse button to orbit and scroll the mouse wheel to zoom; simple clicks still paint stickers or pick center colors without modifying the cube state. Orbiting or resetting the main 3D camera rotates all left-pane 3D thumbnails in real time.

Use the top-right EN / 中文 and theme buttons to switch language or Dark/Light mode at any time. Pressing F1 opens the offline help page matching your active UI language. You can also toggle the left pane dynamically via Options → Expand / Collapse Main Window. Colors, active view, theme, AutoFix, performance profile, and custom shortcuts are persisted in data/preferences.ini.

Flexible Formula Parsing

Formula input accepts standard space-separated moves as well as spaceless sequences and common notation variants:

Example InputCanonical MovesNotes
RUR'U'R U R' U'Spaceless parsing works for outer, wide, slice & rotations (e.g. rUR'U'r'FRF', M2UM2U2)
R'2 / r'2 / Rw'2R2 / r2 / r2Prime-before-2 half turns and R2' are accepted interchangeably
Rw / RW / rrWide turns (outer + adjacent slice), counted as 1 move
M E S / x y zSlices / RotationsM/E/S follow L/D/F; x/y/z follow R/U/F
(R U)2 / (R U)'2 / R’U²Grouped / Inverted / UnicodeAccepts curly quotes, superscript ², fullwidth punctuation, and legacy R-1/Rs/Ra
In formulas, lowercase letters (e.g. r) denote wide turns. In 54-character facelet strings (Edit → Input Facelet String), lowercase letters denote orientation-ignored stickers.

Results Pane, One-Click Copy & Multi-Threaded Optimal Search

Each row in the left results list displays a view-synced cube thumbnail, Solve/Gen toggle, maneuver (Mode 1 rows include a minimalist top-right Copy icon that turns into a green check when clicked; formula results show [MCC x.x]), editable pattern name, Opt checkbox, and Run/Stop button. Click to select, Ctrl-click to toggle, Shift-click for ranges, and right-click the cube thumbnail for Copy, Transfer to Editor, Replay, Invert, Multiply, or Delete.

Checking Opt and clicking Run starts the multi-threaded 3-axis coordinate IDA* optimal solver with a lazy exact 8-corner pruning table and forward/inverse root selection. The optimal marker * appears only after the solver mathematically proves no shorter maneuver exists.

Formula Search, Pre-Rotation, Fine Limits & MCC Sorting

  • Modulo U: Enabled by default; stops as soon as the state reaches the target up to logical U/U'/U2 without appending trailing U turns. Any required leading U is preserved as a real move and bracketed as [U] for display only.
  • Cross Quick Solver & Initial Pre-Rotation (4 / 24 Orientations): The Cross Quick Solver defaults to White bottom (any of the 6 colors selectable) and displays 3-color swatch F2L color pairs (e.g. W-BR Pair) for 0–4 pairs. Under Advanced Settings → Pre-Rotation, choose Horizontal y/y2/y' (4 orientations) or Full x/y/z (24 orientations): pre-rotations happen before the first turn only, with no mid-solve rotations, while guaranteeing the bottom center finishes on physical D (supporting wide/slice setups like [x'] R r U). Pre-rotations are bracketed as [y'] in output.
  • Fine Limits & Per-Move Bans: Left-click toggles a move letter; right-click any move checkbox to individually ban 90°, 180°, or -90°, or expand Advanced Settings and click Fine Limits for the full 54-move matrix. Banning half turns like F2 strictly prevents equivalent consecutive or commuting workarounds such as F F, F' F', or F B F.
  • Quick Copy & Native MCC Fingertrick Sorting: Inside the Formula Window, double-click any result line (or right-click Copy) to copy the formula with a floating ✓ Copied to clipboard toast. Built-in C++20 Trangium MCC scoring lets you switch Sort Order (Default / HTM / MCC) live, and tune all 10 parameters plus Ignore pre-AUF (leading U) under Advanced Settings → MCC Setup.

Performance Profiles & Resource Safety

Choose a concurrency profile under Options → Performance:

  • Quiet (~50% cores): Minimal fan noise and background load.
  • Balanced (Default): Leaves 1–2 logical cores free and lowers background solver thread priority so the desktop stays responsive.
  • Full Speed (All cores): Uses all CPU cores for maximum throughput on deep optimal or formula searches.

Pruning cache budgets automatically adapt to available system RAM, and every single output maneuver is independently verified by a 54-sticker geometric facelet simulator before display.

AI / MCP Batch Integration

mcp/CubeExplorerMcp.exe exposes a local stdio MCP server backed by CubeExplorerEngine.exe with no external API key required. Pre-populated paths are included in mcp-config.json, providing get_capabilities, validate_cube, apply_moves, submit_solve, validate_templates, submit_templates, get_job, get_results, and cancel_job. See MCP Documentation for the full schema.
